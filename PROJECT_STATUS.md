# Project status

Bitcoin 09 was discontinued on 26 August 2026.

Closed project-operated functions:

- website and public API operations;
- explorer, seed, pool, relay, and status services;
- Discord bots and official community support;
- OTC order creation and escrow;
- funding and payment creation;
- exchange applications and listing outreach;
- software releases and maintenance.

The repository and existing release files are retained as a historical archive.
Old wallet files remain the responsibility of their holders. Nobody should send
funds to an old project-controlled address.

A proof-of-work network is peer to peer. Independent copies of the software or
chain may still exist after the official project is closed. They are not an
official continuation and are not operated or guaranteed by this repository's
former maintainer.
