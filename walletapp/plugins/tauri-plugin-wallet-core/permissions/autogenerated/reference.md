## Default Permission

Wallet operations used by the BTC09 mobile app

#### This default permission set includes the following:

- `allow-status`
- `allow-create-wallet`
- `allow-restore-wallet`
- `allow-unlock`
- `allow-lock`
- `allow-receive`
- `allow-activity`
- `allow-preview-send`
- `allow-confirm-send`
- `allow-cancel-send`
- `allow-recovery-phrase`
