Project archive

Bitcoin 09 has been discontinued.

The official project closed on 26 August 2026. Its source and existing releases remain available as a historical record.

Official infrastructure, support, funding, exchange outreach, Discord automation, and escrow are closed.

Do not send coins or payments to any old bot, escrow, deposit, or support address.

What remains

The code and old release files are preserved for reference. They are no longer maintained or supported. A peer-to-peer chain may continue wherever independent users still run nodes; that is not an official continuation.
