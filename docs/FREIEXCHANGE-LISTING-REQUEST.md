## Relevant Information

Bitcoin 09 is a live native UTXO chain launched on 5 July 2026. It is not a
token. There was no premine, ICO, team allocation, or project treasury, and the
genesis reward is unspendable. Every circulating coin was publicly mined.

09C uses Argon2id proof of work with a 64 MiB memory cost, a 21 million maximum
supply, 50 09C starting subsidy, 210,000-block halvings, and a 10-minute block
target. Release v0.1.34 activated per-block ASERT difficulty adjustment at
height 12,096. The node is a small MIT-licensed Go implementation with Linux
amd64 and arm64 builds, checksums, versioned deposit-scanning endpoints, and
documented exchange withdrawal and reorg handling.
