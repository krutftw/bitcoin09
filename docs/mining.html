The proof of work

09C hashes an 88-byte little-endian block header with Argon2id at 64 MiB of memory, one pass, one lane, using the salt BTC09/pow/v1. Every hash attempt needs its own 64 MiB workspace, so throughput is governed by memory bandwidth rather than raw arithmetic speed. Difficulty retargets every block using ASERT, active since height 12,096.

The consensus source of truth is core/pow.go, with core/block.go and core/params.go. Anyone writing a miner should confirm it produces byte-identical digests to the node before mining with it.

What the network looks like right now

Being straight about this matters more than recruiting hashrate. 09C was designed around CPU mining, and that is no longer what secures it. Argon2id at 64 MiB with a single pass is bound by memory bandwidth, which suits graphics cards better than the original design assumed. Since roughly height 12,000 the large majority of blocks have come from GPUs, and one pool currently holds close to all of the network hashrate.

What that means for you, plainly: a CPU still mines valid blocks and the official client still supports it, but a CPU competes against cards doing the same work many times faster, so expect very little from one. The live numbers, including hashrate and how concentrated block production is, are published at explorer.btc09.org/api/status. Nothing there is hidden.

The official pool

The project runs a PPLNS pool with no fee and no minimum payout. Payouts are not a balance you wait to withdraw. Every miner in the share window is paid directly in the block's own coinbase transaction, so the chain itself is the payout record.

https://btc09.org

Live pool state, including hashrate, the window it was measured over, miner count and fee, is public:

https://btc09.org/api/v2/pool/status

The protocol is documented in PPLNS-MINING-PROTOCOL.md. Solo mining against your own node is documented in OPEN-MINING-PROTOCOL.md.

Start here: the miner is already in the wallet

You do not need to download separate mining software. The Bitcoin 09 client ships with its own miner built in. Open the client, choose Mine, pick how many CPU threads to use, and press Start mining. It pays into the wallet address already in front of you, and it mines against the pool above at no fee, so you are not handing a cut to anyone.

The screen shows whether your machine is ready, your current and session-average hashrate, total hashes, jobs received, and blocks accepted, so you can tell at a glance whether it is actually working. It uses the pool without downloading the whole chain first, so it runs in the wallet's fast mode.

Downloads and checksums for Windows, macOS, Linux and Android are on the home page and in the latest release. This is the only miner this project writes, signs and supports.

To mine solo against your own node from the command line instead, with the reward paid straight to your wallet and no pool involved:

./btc09 node -mine

That prints your reward address at startup. Coinbase rewards mature after 100 blocks, the same as Bitcoin.

Community-built accelerated miners

The official miner above is a CPU miner, and this project publishes no GPU miner. Other people have written their own. Leaving that unsaid would only mean you find them through a stranger's download link instead.

Two are open source, are built against the consensus files listed above, and gate themselves on producing digests byte-identical to the node's CPU implementation before they will mine:

  • btc09-cuda-miner, an NVIDIA CUDA miner covering Turing through Blackwell.
  • btc09-apple-silicon-miner, a Metal miner for Apple Silicon.

Read this part carefully. These are third-party projects. They are not written, reviewed, audited, endorsed, or supported by Bitcoin 09, and their authors owe you nothing. Both repositories ship prebuilt binaries. Build from source yourself if you can, and read the code before you run it. Check the licence terms in each repository before you use, modify, or redistribute anything from them. If any miner asks for your recovery phrase, private key, wallet file, remote access, or a Discord token, it is stealing from you. A mining program only ever needs a payout address.

Choosing where to point it

You are free to mine wherever you like, including against your own node. Two things are worth knowing when you choose. A pool holding most of a small network's hashrate can reorganise that chain, so hashrate spread across several pools is worth something to everyone mining the coin, including you. And pool fees are real money: this project's pool takes nothing, which is a deliberate choice rather than an introductory offer.

Where 09C trades

09C is not listed on any exchange yet, so there is no market price. Peer-to-peer trades happen through the project's Discord with an escrow bot, and every listing application, rejection and blocker is published rather than summarised.
