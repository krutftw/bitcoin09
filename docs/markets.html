How It Works

  1. Draft the trade record on this page.
  2. Use the copied text in Discord #💱-otc-trading if you want quick negotiation.
  3. For escrow, the seller starts with /sell in Discord, deposits 09C, then the buyer accepts with /buy.
  4. After off-chain payment, both sides use /confirm. If it gets stuck, use /dispute.
  5. Open the public GitHub record when the offer or completed trade should be visible on the board.
  6. Add only public proof: 09C tx link, redacted screenshot, or short note. Do not upload private payment account details.

How To Send 09C

09C is its own chain, not an Ethereum, Solana, or token contract asset. MetaMask and Phantom do not support it. Use the Bitcoin 09 wallet/node for now.

btc09 wallet list
btc09 send -to THEIR_09C_ADDRESS -amount 100 -seeds 178.128.105.41:9009

Default fee is 0.0001 09C. -seeds is plural and means peer nodes to broadcast through, not a wallet seed phrase. Do not paste private keys, seed phrases, or wallet file contents into the command line. send spends from the wallet file in your data directory. Your local chain must be synced enough to see spendable coins, and mined rewards become spendable after 100 blocks.

Ground Rules
