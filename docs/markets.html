How It Works

  1. Use Discord #💱-otc-trading for quick negotiation.
  2. Click a board button to create a public GitHub record.
  3. Add only public proof: 09C tx link, completed-trade screenshot, or short note. Do not upload private payment account details.
  4. The board reads GitHub issues and updates automatically.

Scam Checks

  • Public first. Be careful when someone moves straight to DMs.
  • No guaranteed profit, no urgent pressure, no "official floor".
  • Use a tiny test trade before a larger one.
  • Check the 09C address or tx on the explorer when possible.
  • Never upload payment account details, private keys, seed phrases, wallet files, Discord tokens, or remote access screenshots.

How To Send 09C

09C is its own chain, not an Ethereum, Solana, or token contract asset. MetaMask and Phantom do not support it. Use the Bitcoin 09 wallet/node for now.

btc09 wallet list
btc09 send -to 4THEIR_09C_ADDRESS -amount 100 -seeds 82.22.32.82:9009

Default fee is 0.0001 09C. Your local chain must be synced enough to see spendable coins. Mined rewards become spendable after 100 blocks.

Ground Rules

  • Trade small first.
  • Never share seed phrases, private keys, wallet files, Discord tokens, or remote access.
  • Staff will not DM you first and does not provide official escrow.
  • No fake volume, wash trades, pump groups, price promises, or impersonation.
  • Use public completed-trade records for factual price discovery, not hype.
