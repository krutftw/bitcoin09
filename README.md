# Bitcoin 09 (09C) — discontinued

Bitcoin 09 was a fair-launch proof-of-work experiment with a 21 million coin
cap, ten-minute target blocks, no premine, and Argon2id mining.

The project was discontinued on 26 August 2026. Official infrastructure,
support, fundraising, exchange outreach, Discord automation, and escrow are
closed. Do not send coins or payments to any old bot, escrow, deposit, or
support address.

The source, documentation, and existing release files remain here as a
historical archive. They are no longer maintained or supported. A
peer-to-peer chain may continue wherever independent users still run nodes;
that does not mean the former project operates or guarantees the network.
