# Bitcoin 09 Brand

Bitcoin 09 should look like a small early network, not a polished exchange
product. Keep it plain, technical, and easy to verify.

## Name

- Project: Bitcoin 09
- Ticker: 09C
- Short line: the coin that you can mine like it's 2009
- Longer line: CPU proof of work, 21M cap, no premine

Use `Bitcoin 09` on first mention. Use `09C` as the ticker after that.

## Logo Files

- Main mark: `docs/assets/bitcoin09-ai-logo.png`
- Web/README mark: `docs/assets/bitcoin09-ai-logo-512.png`
- Social preview card: `docs/assets/bitcoin09-social.png`

The mark is the current visual direction: gold coin, dark center, one-line
custom `09C`, and simple chip/circuit cuts around the edge. It should read at
Discord-avatar size first, then scale up for web and social previews. It has
the early Bitcoin-era coin feel without using the Bitcoin B glyph.

Use the 512px PNG for README, Discord, web pages, pool pages, and listing forms.
Keep the full-size PNG as the source artwork.

## Voice

Good:

- "Mine it because it's fun and you missed 2009."
- "No premine, no allocation, no price promises."
- "The pool miner count means connected payout addresses, not unique people."

Avoid:

- price predictions
- exchange-style hype
- fake urgency
- claims that 09C is an investment

## Third-party Miners

The official Bitcoin 09 software is the `btc09` reference node, wallet, solo
miner, and explorer.

Do not recommend a specific third-party miner. Several exist, including
closed-source binary-only ones from anonymous operators, and this project has
audited none of them. Public materials may state that third-party miners exist,
link their source repositories, and say plainly that they are not written,
reviewed, endorsed, or supported here. Do not link prebuilt binaries and do not
name a preferred vendor.

Any pool miner only ever needs a payout address. Never give one a seed phrase,
private key, wallet file, remote access, or Discord token.
